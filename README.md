# Tormes Hoy

A free (as in freedom) app for Salamanca, with no ads. Check the current
weather and forecast, sunrise and sunset times, UV index, and the latest state
of the Tormes river, all on one screen.

Install it on your phone; no account is needed.

Available at **<https://lpda-sal.github.io/tormes-hoy/>**


## Install the App

Tormes Hoy is a Progressive Web App (PWA): open the link above in your
browser and add it to your device. It then works like a regular app, with its
own icon and full-screen window, and without an app store.

| Browser                 | Platform     | How to install                                                                                                   |
| ----------------------- | ------------ | ----------------------------------------------------------------------- |
| Firefox, Chrome         | Android      | Menu (⋮) → **Install app** (or **Install**, or **Add to Home screen**). |
| Samsung Internet        | Android      | Menu (≡) → **Add page to** → **Home screen**.                           |
| Safari, Firefox, Chrome | iPhone, iPad | **Share** button → **Add to Home Screen** → **Add**.                    |

Tips:

  - The menu entries may vary slightly between browser versions and languages.
  - To uninstall, remove the icon like any other app.
